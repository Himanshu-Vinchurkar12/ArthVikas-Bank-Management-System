# ArthVikas-Bank-Management-System

A secure and modular console-based banking application built using Core Java, JDBC, and MySQL.

## Features

- Secure user registration and login
- SHA-256 password hashing
- Deposit, withdrawal, and balance inquiry
- Fund transfer between accounts
- Transaction history management
- JDBC + MySQL integration
- Layered architecture (Controller, Service, DAO, Model)
- Custom exception handling
- Input validation
- Modular and scalable structure

---

## Tech Stack

- Java
- JDBC
- MySQL
- OOP
- Collections Framework
- Exception Handling
- SHA-256
- Git & GitHub
